# Lógó — placeholders

Tólið vísar í eftirtaldar PNG-skrár í þessari möppu. Þær eru **ekki** vistaðar
hér enn — þú þarft að setja þær inn handvirkt eftir að þú hefur staðfest
opinber lógó frá hverjum framboði.

| Skráarheiti | Framboð |
|---|---|
| `a-vinstrid.png`               | A — Vinstrihreyfingin – grænt framboð |
| `b-framsokn.png`               | B — Framsóknarflokkurinn |
| `c-vidreisn.png`               | C — Viðreisn |
| `d-sjalfstaedisflokkur.png`    | D — Sjálfstæðisflokkurinn |
| `f-flokkur-folksins.png`       | F — Flokkur fólksins |
| `g-godan-daginn.png`           | G — Góðan daginn |
| `j-sosialistar.png`            | J — Sósíalistaflokkurinn |
| `m-midflokkurinn.png`          | M — Miðflokkurinn |
| `p-piratar.png`                | P — Píratar |
| `r-okkar-borg.png`             | R — Okkar borg |
| `s-samfylkingin.png`           | S — Samfylkingin |

## Þangað til lógó eru komin

Tólið fellur sjálfkrafa aftur í **stafa-kúlu** (lit-kringt með listabókstaf
framboðsins) ef PNG-skrá vantar. Engin villa kemur upp.

## Heimildir og höfundarréttur

Notið helst lógó sem framboðin sjálf birta opinberlega (forsíða vefs eða
press-kit). Ef ónæg vissa er um höfundarrétt — sleppið lógóinu og notið
stafa-kúluna áfram.
